# Empty States

Use `UDSEmptyStateView` when a collection has no content and a recovery action is not required. For a more flexible placeholder with an optional action button, see [Placeholders](Placeholders.md).

```swift
UDSEmptyStateView(
    title: "No results",
    description: "Try another search term.",
    systemImageName: "magnifyingglass"
)
```

UIKit has a matching `UDSUIKitEmptyStateView`.
